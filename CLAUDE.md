# CLAUDE.md

## Project Overview
This document provides guidance for AI assistants (particularly
Claude) working with the mtsr repository.

The current documentation and code is a presentation of methods, 
applicability, accuracy, precision, and efficiency of the
Momentary Time Sampling (MTS) method for time-on-task estimation.

The primary goal of further development is the implementation of
a server-side application and client-side applications for iOS, Android,
and web to facilitate data collection using the MTS method.

## Repository Structure
```
mtsr/
├── docs - website documentation
├── man: autogenerated function documentation for R functions
├── inst
    ├──  extdata
         ├── todo_notes.qmd - todo notes for further development
         ├── references.bib - bibliography file
         └── customizations
         ├── defined_activities
         ├── presentations -- stub files only
         ├── project_yaml_files
   ├──  papers - contains one paper thus far but others should be added
├── R - R functions for simulations and analysis
└── tests - unit tests for R functions
├── workflows - initial Software Bill of Material (SBOM) generation workflow
```
